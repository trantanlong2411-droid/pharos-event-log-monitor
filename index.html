Pharos Event / Log Monitor

Continuous ERC-20 Transfer watcher built with Chain MCP. Source and reproducible instructions belong in this repository.

How it works

Pharos MCP → get_block_number → filtered get_logs → ABI decoding → persistent checkpoint / deduplication.

Contract: 0x51e2A24742Db77604B881d6781Ee16B5b8fcBE29 (configurable)

Event: Transfer(address,address,uint256)
