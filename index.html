How to reproduce

This project includes an executable monitor, historical replay, an on-disk checkpoint, and deduplication using transaction hash plus log index. The published event data was captured from the chain and can be checked against transaction receipts.

npm install
npm run check
$env:CONTRACT_ADDRESS="0x52c48d4213107b20bc583832b0d951fb9ca8f0b0"
$env:START_BLOCK="20240591"
npm run replay
npm run replay     # expect new=0 for already saved events
Remove-Item Env:START_BLOCK
npm start          # continue watching newly produced blocks

The script's checkpoint and event store are local. Back up or move a checkpoint belonging to another contract before switching. The historical replay confirms decoding; real-time polling was separately observed in terminal tests. The dashboard does not itself poll new blocks.
